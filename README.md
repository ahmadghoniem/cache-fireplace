# clawd-furnace

A Claude Code mod: Clawd keeps a fireplace burning in the band above the prompt, for as long as the prompt cache stays warm.

- A prompt to a cold cache: he throws a log on.
- A prompt to a warm cache: he pokes the fire.
- The cache cooling: he puts on a scarf and rubs his hands.
- The cache expired: ash and smoke.

`/fireplace` shows or hides it.

## Install

```
/plugin marketplace add ahmadghoniem/clawd-furnace
/plugin install clawd-furnace@clawd-furnace
```
